<h1 align="center">MeloNX for tvOS</h1>
<p align="center">
  An unofficial Apple TV port of <a href="https://starforgejo.dev/projects/MeloNX">MeloNX</a> 2.7, the Ryujinx-based Nintendo Switch emulator for iOS.
</p>

> [!WARNING]
> **Still in testing.** This port is under active development and is being tested on real hardware.
> Some games boot and play (Animal Crossing: New Horizons ran for 14 minutes in testing), others may
> crash, show missing graphics, or run out of memory. Expect bugs and frequent builds.

## Requirements

| | |
|---|---|
| Device | Apple TV 4K (3rd generation, A2843, A15). Earlier models are untested. |
| tvOS | 16.x with [TrollStore](https://github.com/opa334/TrollStore) installed (tested on 16.6) |
| Controller | An extended gamepad (Switch Pro Controller, Xbox, DualSense, 8BitDo …). The Siri Remote only drives the menus. |
| Files | Your own dumps: `prod.keys`, firmware `.zip`, and games (`.nsp` `.xci` `.nro`) |

## Install

1. Download `MeloNX.tipa` from [Releases](../../releases).
2. Install it with TrollStore.
3. In TrollStore, select MeloNX and choose **Open with JIT**.
   JIT is required to run games. Launching from the Home Screen icon opens the app without JIT;
   the home screen then shows **JIT: none** and games will not start.

## Where to put your files

tvOS does not let an app write to its own `Documents` folder, so MeloNX keeps the same folder layout as the
iOS app under `Library/Caches/MeloNX` inside its data container. Copy files there with a file browser:

```
/var/mobile/Containers/Data/Application/<UUID>/Library/Caches/MeloNX/
├── roms/       games: .nsp .xci .nro (sub-folders are fine)
├── system/     prod.keys, title.keys
├── firmware/   firmware .zip  → then press "Install firmware" on the home screen
├── music/      optional: your own .mp3/.m4a for the menu music
└── Logs/       tvos-app.log, stdout.log, stdout.prev.log (previous run)
```

The full path is shown on the home screen. Firmware is required: without it, games stop at boot because the
system fonts and time-zone data are missing.

## Using it

- **Games tab**: status of JIT, gamepad, keys, firmware and memory, then your game library.
- **Settings tab**: resolution scale, TV (docked) mode, aspect ratio, VSync, anti-aliasing, scaling filter,
  anisotropic filtering, texture recompression, shader cache, system language/region, game volume,
  controller type, memory manager, menu music, debug logs. Changes apply from the next game start.
- **Pause / quit**: Siri Remote **Menu** button, or press **− + L R** together on the gamepad.
- **Menu music** plays on the library screen. It is an original tune generated by the app, or the first file in `music/`.

## What is different from MeloNX on iOS

- **JIT** comes from TrollStore attaching a debugger ("Open with JIT"), like MeloNX on iPad.
  The `dynamic-codesigning` entitlement is banned on A12+ devices and makes the app crash at launch, so it is not used.
- **Memory**: tvOS gives an app about 2 GB by default and RunningBoard keeps resetting the limit.
  The app raises it to ~3.4 GB at launch, at game start and every 5 seconds while playing.
- **Rendering** runs at 1080p (tvOS upscales to 4K). MetalFX, AirPlay, touch controls and device motion are not included.
  Motion from controllers with a gyro (e.g. DualSense) is passed through.
- **MoltenVK** is built from source with two patches:
  tvOS uses the iOS Metal feature table (same A15 GPU as an iPhone 13), and an invalid compute pipeline is never dispatched.
- **Core fixes for Apple TV**: placeholder vertex attributes match the shader's input type, graphics pipelines without a vertex
  stage are skipped, a lost Metal device no longer ends the game, the controller applet no longer loops forever, and
  FFmpeg (in-game video) is loaded from the app bundle.

## Troubleshooting

When something goes wrong, send these files from `Logs/`:

- `tvos-app.log`: launch steps, memory limit, JIT state. After a crash it shows the signal, the faulting
  module (for example `libMoltenVK.dylib +0x…`) and the call stack.
- `stdout.log` / `stdout.prev.log`: core and GPU output. Open the app again after a crash and send `stdout.prev.log`.
- Crash reports: `/var/mobile/Library/Logs/CrashReporter/MeloNX-*.ips`

## Building

Everything builds on GitHub Actions (no Mac needed): `.github/workflows/build-tvos.yml`

```
deps ─┐  MoltenVK 1.4.0 (patched) · SDL3 · FFmpeg 6.1 for appletvos    cached
core ─┼▶ app   Ryujinx core via .NET NativeAOT (tvos-arm64)             cached
      ┘        XcodeGen (project-tvos.yml) → xcodebuild → ldid → MeloNX.tipa
```

To publish a release, run the workflow manually with a `release_tag` (for example `tvOS-v2.7.0-12`),
or push a `tvos-v*` tag.

Source layout:

| Path | Contents |
|---|---|
| `tvos/App/` | tvOS app: launch, paths and logging, JIT and memory, controllers, library, settings, emulation view, menu music |
| `src/MeloNX/MeloNX/Core/` | iOS core bridge reused as-is (`Ryujinx.swift`, options, controllers) |
| `src/Ryujinx.*` | Ryujinx/MeloNX C# core, with `IsTvOS()` added wherever `IsIOS()` is checked |
| `tvos/scripts/` | dependency build (with the MoltenVK patches) and `.tipa` packaging |
